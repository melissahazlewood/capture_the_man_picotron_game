# Capture the Man: A Picotron Game
A simple game where a pink-faced man becomes a *growing* concern. Capture him!

## Gameplay
A pink-faced man will slowly grow in size while the player attempts to ensnare him by setting a perfectly sized trap (a white circle). The player's job is to change the size of that circle using the up and down arrow keys to completely surround him. Upon pressing the space bar, the trap is set and the man stops growing. If no circle pixels overlap with the pink-faced man, the player wins! Points are earned for speed and least pixel overlap.

## Controls
↑ : Increase the circle radius

↓ : Decrease the circle radius

SPACE: Stop the pink-faced man's growth

## Development
Programmed in Lua using Picotron. All art created internally without the use of AI.
